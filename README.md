# Forms Implementation Assignment

This project implements the Forms Implementation Assignment.

## Requirements completed

- HTML form with user input fields
- JavaScript submit event handling
- `event.preventDefault()` to stop default form submission
- Submitted data stored in an array
- Submitted data displayed in a search box
- Search box updates dynamically after every submission
- Submitted data is also displayed in an output area

## Run

Open `index.html` in a browser.
